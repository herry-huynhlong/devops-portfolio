13. LƯU Ý CTRL+C VÀ CTRL+Z
------------------------------------------------------------

Khi chạy process foreground:

  Ctrl+C = dừng process

KHÔNG nên dùng:

  Ctrl+Z

vì Ctrl+Z chỉ suspend process.
Process vẫn có thể giữ port 3000 và gây:
  EADDRINUSE
  504 Gateway Time-out

Nếu port bị process cũ giữ:

  sudo fuser -k 3000/tcp

sau đó:

  sudo systemctl restart portfolio

14. NGINX - REVERSE PROXY
------------------------------------------------------------

File:

  sudo nano /etc/nginx/sites-available/portfolio

Mẫu HTTP:

server {
    listen 80;
    listen [::]:80;

    server_name TEN-MIEN-CUA-BAN www.TEN-MIEN-CUA-BAN;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

Kiểm tra config:

  sudo nginx -t

Reload:

  sudo systemctl reload nginx

Nếu sửa config Nginx:
  nginx -t
  rồi reload

Không cần restart Next.js nếu chỉ sửa Nginx.

15. THÊM TÊN MIỀN
------------------------------------------------------------

Bước 1:
Nên gán Elastic IP cho EC2 để IP không đổi khi reboot/stop-start.

Bước 2:
Ở nhà cung cấp DNS, tạo:

A record:
  @
  -> ELASTIC-IP

A record:
  www
  -> ELASTIC-IP

Hoặc:

CNAME:
  www
  -> TEN-MIEN-CUA-BAN

Bước 3:
Sửa Nginx:

  sudo nano /etc/nginx/sites-available/portfolio

Đổi:

  server_name _;

thành:

  server_name example.com www.example.com;

Bước 4:

  sudo nginx -t
  sudo systemctl reload nginx

Bước 5:
Kiểm tra DNS:

  nslookup example.com

hoặc:

  dig example.com

16. THÊM HTTPS / SSL LET'S ENCRYPT
------------------------------------------------------------

  sudo certbot --nginx -d example.com -d www.example.com

- cấu hình HTTPS

  https://example.com

Test renewal:

  sudo certbot renew --dry-run

18. THÊM DOMAIN MỚI
------------------------------------------------------------

Ví dụ đang có:
  olddomain.com

muốn thêm:
  newdomain.com

DNS:
  newdomain.com -> Elastic IP

Nginx:

server_name olddomain.com www.olddomain.com newdomain.com www.newdomain.com;

Sau đó:

  sudo nginx -t
  sudo systemctl reload nginx

Thêm SSL:

  sudo certbot --nginx \
    -d olddomain.com \
    -d www.olddomain.com \
    -d newdomain.com \
    -d www.newdomain.com

------------------------------------------------------------
19. XÓA DOMAIN CŨ
------------------------------------------------------------

Bước 1:
Sửa Nginx:

  sudo nano /etc/nginx/sites-available/portfolio

Xóa domain cũ khỏi:

  server_name

Bước 2:

  sudo nginx -t
  sudo systemctl reload nginx

Bước 3:
Xóa DNS record cũ ở nhà cung cấp DNS nếu không còn dùng.

Bước 4:
Nếu muốn dọn certificate cũ:

  sudo certbot certificates

Sau đó dùng:

  sudo certbot delete --cert-name TEN-CERTIFICATE

Chỉ xóa certificate khi chắc chắn domain không còn sử dụng.

------------------------------------------------------------
20. ĐỔI DOMAIN
------------------------------------------------------------

Ví dụ:
  old.com -> new.com

Làm theo thứ tự:

1. Trỏ DNS new.com -> Elastic IP
2. Thêm new.com vào server_name Nginx
3. nginx -t
4. reload nginx
5. chạy certbot cho new.com
6. kiểm tra HTTPS new.com
7. sau khi ổn mới xóa old.com

Không nên xóa domain cũ trước khi domain mới hoạt động.

------------------------------------------------------------
21. REDIRECT DOMAIN CŨ SANG DOMAIN MỚI
------------------------------------------------------------

Ví dụ:

server {
    listen 80;
    server_name old.com www.old.com;
    return 301 https://new.com$request_uri;
}

Nếu old.com có HTTPS thì nên giữ certificate cho old.com trong thời gian redirect.
